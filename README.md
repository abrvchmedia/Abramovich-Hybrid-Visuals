# Abramovich Hybrid Visuals - Financial Projections

Professional investor-ready financial projections for four revenue tiers: **$100K**, **$500K**, **$1M**, and **$2M+**.

## 📦 What's Included

Each tier includes:

✅ **12-Page Professional Investor Memorandum (PDF)**
- Executive cover with key metrics
- Business model & assumptions
- Division P&Ls (Production, Marketing, Media)
- Consolidated financials with charts
- Cash flow analysis
- Scenario analysis (Conservative/Target/Upside)
- Investor recoupment waterfall
- Financial ratios & metrics

✅ **Detailed Financial Models (Excel & JSON)**
- Complete 3-year projections
- Quarterly breakdowns
- Multiple scenarios
- All assumptions documented

✅ **Professional Charts & Graphics**
- Revenue by division
- Margin analysis
- Cash flow visualization
- Revenue mix pie charts
- Scenario comparisons
- Investor waterfall

## 🚀 Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Generate all projections
python3 generate_all.py
```

Output files will be in the `output/` directory.

## 🎯 Business Model

### Three Revenue Streams:

1. **Production Division** (40-60% of revenue)
   - Premium video production
   - 50-58% gross margins

2. **Marketing Division** (30-45% of revenue)
   - Monthly recurring retainers
   - 75% gross margins
   - Stable cash flow

3. **Media/Distribution** (10% of revenue)
   - Media deployment services
   - 85% gross margins

## 💼 Investor Structure

- **Investment**: 50% of Year 1 target revenue
- **Recoupment**: Investors receive 100% of operating cash flow until capital is repaid
- **Post-Recoupment**: 50/50 profit split
- **Timeline**: Recoupment expected Year 2-3 (varies by tier and scenario)
